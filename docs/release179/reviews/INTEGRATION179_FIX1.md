## New fix-diff finding

### F1 — Important: the new output identity parameter breaks the Host export wrapper

`app/src/main/java/uk/co/traynor/privategallery/core/evidence/EvidenceDocumentIo.kt:44` changes `write` to `(uri: Uri, protectedSource: Uri? = null, consume: (OutputStream) -> T)`. The existing production wrapper at `app/src/main/java/uk/co/traynor/privategallery/ui/EvidenceLockerHost.kt:142` still calls `it.write(uri,write)`.

That positional second argument now binds the output function to `protectedSource`, which requires `Uri?`, and leaves required `consume` unsupplied. Kotlin does not skip an intermediate default parameter for a positional argument. This prevents the main source set from compiling, including both ordinary encrypted and explicit plaintext export paths using `evidenceDestination`.

Use the named argument `it.write(uri, consume = write)` (or the equivalent trailing lambda), preserving the protected-source argument on archive re-export. Recheck the affected call sites and include the corrected source in the mandatory grouped Kotlin/Android build. This is established from the actual signature/caller, not a claimed compiler execution. No other new fix-diff finding was established.
