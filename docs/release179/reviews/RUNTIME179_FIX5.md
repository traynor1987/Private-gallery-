## Specification and quality assessment

- **Keyboard/root/thread preconditions:** the production Locker uses a real Compose `Dialog`, with `imePadding`, and only that dialog is open at this point in this isolated fixture. Espresso `onView(isRoot()).inRoot(isDialog())` consequently targets its native root rather than the activity behind it. The supported `ViewActions.closeSoftKeyboard()` action is appropriate on a root; Espresso's own documented implementation uses `onView(isRoot()).perform(ViewActions.closeSoftKeyboard())`. Existing `espresso-core:3.7.0` supplies the API. The view is captured by the Espresso assertion on the UI thread, then read through `compose.runOnIdle`, also on the UI thread. The surrounding JUnit interaction runs off the UI thread. There is no direct off-thread view mutation.
- **IME condition:** `rootWindowInsets` and `WindowInsets.Type.ime()/isVisible` are available below the project's minimum/compile API 37. The wait requires an actual `false`; null view/insets cannot satisfy it. A detached root therefore does not silently pass. Dismissing through the IME action does not invoke Back navigation or clear the search, and the subsequent assertion explicitly preserves Alice. The observed hidden inset is a useful viewport precondition, not proof that every possible future layout change is excluded; Compose settling and the subsequent materialization/state checks still matter.
- **Selection/open synchronization:** before selection and after selection recomposition, the code uses the known `evidence-list` LazyColumn directly and unconditionally. It waits for a unique displayed checkbox, injects exactly one checkbox `performClick()`, settles and rematerializes, then waits for the actual On/displayed state and asserts it. The replaced conditional shared helper is absent at both selection and opening boundaries; no shared helper rewrite, semantics-action click, direct callback, injected-tap retry, arbitrary sleep, matcher broadening or assertion weakening was introduced. A timeout or gesture failure remains a failure.
