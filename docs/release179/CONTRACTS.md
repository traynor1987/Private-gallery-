# Evidence179 implementation contracts

Package `uk.co.traynor.privategallery.core.evidence`. Java17 immutable records below are shared by Kotlin UI/Android adapters. Accessors are Java record methods. No shared product-file writer: model/store agent owns listed Java files; root owns controller/Main/UI; OCR and export/AI agents own their adapters.

## Pure model and encrypted store

`EvidenceCatalog` immutable final class: `Owner {PRIMARY,HIDDEN}`; constructor `EvidenceCatalog(Owner,long revision,List<Evidence>,List<Incident>,List<Audit>,List<Analysis>,List<String> rejectedSuggestions)`; `empty(Owner)`, `owner()`, `revision()`, `evidence()`, `incidents()`, `audit()`, `analyses()`, `rejectedSuggestions()`, `encode():byte[]`, `decode(byte[],Owner):EvidenceCatalog`.

Nested public records (validate/bound/copy all collections):
- `Metadata(String sourceName,long fileCreatedAt,long fileModifiedAt,long dateAddedAt,long captureAt,int width,int height,Map<String,String> embedded,boolean vaultOnly)`. Zero dates/dimensions mean unavailable; source claims never independent verification.
- `Word(int pageIndex,String text,float confidence,int left,int top,int right,int bottom)` confidence0..100 or-1 unknown.
- `ExtractedTime(int pageIndex,String text,long epochMillis,String provenance,float confidence)` epoch0 unknown; no silent year/zone inference.
- `Ocr(String id,long createdAt,String engine,int rotation,int width,int height,String text,float confidence,List<Word> words,List<ExtractedTime> times,int pageCount,boolean partial)`; max8 complete extraction versions/record, independent of page count. Reject a ninth extraction rather than silently discard history.
- `Correction(String id,String ocrId,long createdAt,String text)` append-only raw-preserving transcript revision.
- `Evidence(String id,String sourceId,String name,String mime,String sha256,long size,long importedAt,Metadata metadata,String description,String notes,List<String> tags,List<String> participants,List<Ocr> ocr,List<Correction> corrections)`; `transcript()` returns latest matching correction or latest raw extraction; sourceId is originating vault UUID, never URI/path.
- `Event(String id,List<String> evidenceIds,long timestamp,String provenance,String title,String notes)` provenance `SOURCE_CAPTURE`, `EXTRACTED`, `USER`, `INFERRED`, `AI_INFERRED`; epoch0 unknown.
- `SourceFingerprint(String sourceId,String mime,String sha256,long size,boolean vaultOnly)` immutable contributing-source policy/integrity identity.
- `Incident(String id,String title,long startAt,long endAt,String description,String notes,List<String> tags,List<String> evidenceIds,List<Event> events,boolean manualOrder,boolean archived,List<SourceFingerprint> lineage)`.
- `Audit(String id,long at,String action,List<String> targetIds,String detail)` local owner-approved log, not legal certification.
- `Analysis(String id,long at,String model,String task,String inputDigest,List<String> evidenceIds,String text,long inputTokens,long outputTokens,boolean applied,List<SourceFingerprint> lineage)` advisory text separate from originals.
- `Suggestion(String id,String kind,List<String> evidenceIds,String incidentId,String title,List<String> reasons)` stable digest identity, hints only; no automatic merges.

Functional immutable methods: `upsertEvidence(Evidence,long now,String action)`, `removeEvidence(String id,long now)` (detach references, never delete original), `upsertIncident(Incident,long now,String action)`, `deleteIncident(String id,long now)` (references only), `assign(List<String> ids,String incidentId,boolean move,long now)`, `unlink(List<String> ids,String incidentId,long now)`, `merge(String targetId,List<String> sourceIds,long now)` (source incidents archived, information preserved), `split(String sourceId,List<String> ids,String newId,String title,long now)`, `archive(String id,boolean archived,long now)`, `saveOcr(String evidenceId,Ocr,long now)`, `reviseOcr(String evidenceId,String ocrId,String text,long now)`, `saveAnalysis(Analysis,long now)`, `moveEvent(String incidentId,String eventId,int index,long now)`, `rejectSuggestion(String suggestionId,long now)`, `acceptSuggestion(Suggestion,String newIncidentId,String title,long now)`. Each mutation validates current IDs, increments revision once and appends audit; no-op must not fabricate mutation. Chronological sorting `timeline(String incidentId):List<Event>` sorts known timestamps, preserves labelled unknowns; manual mode preserves stored event order. `search(String query,long from,long through,boolean includeArchived):List<Evidence>` searches names, text, notes, tags, explicit participants and linked incident title; date filters use sourced import/capture dates explicitly. `suggestions():List<Suggestion>` uses bounded time/text/participant/hash signals; no implicit apply.

Capacity: catalog encoded maximum4MiB (existing HiddenRecordStore metadata limit),4096evidence,1024incidents,20000audit,100000OCR chars/extraction,256tags/participants,64K notes. Reject quota/corruption before overwrite; never silently drop audit/data. Codec is versioned bounded binary UTF8, rejects foreign owner/duplicate IDs/trailing/truncated data. Originals immutable; annotations/corrections separate.

`EvidenceEncryptedStore(File root,Owner owner,LeaseFactory)` reuses existing HiddenRecordStore metadata AES-GCM/atomic verified staging, with HMAC-SHA256 domain-derived evidence key and distinct fixed record UUIDs per owner. It never changes existing media/index files. Nested `LeaseFactory {KeyLease acquire() throws Exception;}`; `KeyLease extends AutoCloseable {byte[] key(); boolean current(); void commit(CommitAction action)throws Exception; void close();}`; `CommitAction {void run()throws Exception;}`. `read():EvidenceCatalog`; `update(UnaryOperator<EvidenceCatalog>):EvidenceCatalog`. Acquire/wipe keys per operation, reject stale read/commit, stage/promote only inside captured commit gate, sync directory, wipe encoded/decrypted/derived buffers; clean only own ciphertext staging. Root constructs Primary identity+generation+authentication gate and HiddenSession operation leases.

## Android adapters

`EvidenceOcr(Context)` implements `suspend fun recognize(bytes:ByteArray,mime:String,rotation:Int,current:()->Boolean):EvidenceCatalog.Ocr`; caller owns original bytes. Bundled Tesseract4Android4.9.0 + pinned tessdata_fast4.1.0/eng; no runtime network. Private model files contain only public model. Decode bounds <=16MP, working long edge<=2048; preserve source dimensions separately. First cancellable hOCR recognition, then text/word geometry/confidence; bounded30s per image/PDF page and120s whole document, stop on cancellation/revocation, recycle after native recognizer exits. No plaintext images/text on disk. UTF8 text/CSV extraction uses engine UTF8_DOCUMENT with unavailable confidence (-1), not a fabricated OCR confidence. PDF raster OCR reuses VaultPdfPreview memory-only proxy descriptors, max32 pages, page-indexed word/time coordinates; mark partial with an explicit explanation when more pages/text exceed limits. Preserve full original bytes regardless of extraction limit; no active content.

Root `EvidenceController` captures owner/session access, encrypted store, source providers, current fence; operates IO offMain and publishes UI only on Main. A source adapter lists same-vault COMPLETE original VaultItems, reads bounded bytes or streams complete verified original through existing repository APIs, imports SAF into originating encrypted repository without altering bytes. Record registration hashes actual verified bytes and records independent timestamp provenance. Never delete/trash underlying originals for record/incident removal. On unavailable/changed original mark status and require owner reverify; no silent rehash overwrite. `vaultOnly` restriction inherits into transcripts/AI/export and is rechecked against live original, never overridden by notes/edits.

`EvidenceExport` produces password-encrypted `.pgevidence` container: versioned authenticated header+scrypt N32768/r8/p1 salt16+AES256-GCM nonce12/tag128, standard existing crypto primitives; inner ZIP includes report.pdf, evidence.json, hashes.json and byte-identical originals under generated safe UUID names. Platform PdfDocument; no password claim for PDF itself. SAF encrypted staging/copy/partial cleanup, owner cancellation, max bounded metadata/PDF, originals streamed authenticated toEOF. Plaintext ZIP requires separately confirmed plan; blocked for vaultOnly originals/derived content even when encrypted. Provide app Open encrypted export/password/verify and explicit re-export plaintext to make report accessible. Never public temporary plaintext. Export passphrase chars preserved verbatim, min12, recommendgenerated20; KDF parameters fixed and parser bounds beforeKDF. Wrongpassword/truncated/tagtamper neverpublish plaintext.

`EvidenceAi` uses Responses exacthttps://api.openai.com/v1/responses, no redirects/cookies/cache, store:false/background:false/stream:false/tools:[], max_output_tokens2048, no billed POST retries. Model choices gpt-5.6-luna/terra (official documented vision/pricing2026-10-31). Preview shows exact selected text/explicit images (default text-only), model/task/route/estimatedUSD/limits/provider retention; immutable bytes+selection catalogrevision/sourcehash+routeidentity bound to one-shot confirmation. No filename/location/unrelated evidence. API key read only on send, owner-scoped protected credentials, never preview/log/export. Output advisory and labelled, references validated, user separately confirms application to incident/timeline. Local features continue on unavailable provider/key/network.

Network: Primary uses existing authorised AI system transport explicitly labelled; Hidden chooses verified ownedVPN (socketFactory+OwnedVpnDns) or existing Tor-isolation/privateUnix SOCKS via HiddenVpnProxy with authenticated loopback and originDNS prohibited. No direct fallback. Root provides connected immutable route lease before consent; AI adapter owns/cancels calls on lease revocation. New Hidden route coordinator reuses existing HiddenTorIsolationConnection/HiddenTorConnection, not a new WebView/profile. Never enableJS or change browser cookies.


## Resolved design-review contracts (binding)

Store concurrency uses one shared lock per canonical evidence-only root+owner across all store instances. Stage/encrypt/verify outside the short authentication commit monitor; only final promotion inside KeyLease.commit. Pre-promotion failure preserves old ciphertext. A directory fsync failure AFTER promotion is an uncertain-durability failure, not a promise old bytes survived: return failure, reread authoritative state before retry; never blindly replay non-idempotent mutations. Derived evidence key is `HMAC-SHA256(vaultKey, UTF8("private-gallery:evidence:179:v1:"+owner.name()))`; fixed metadata UUIDs Primary `00000000-0000-4000-8000-000000017901`, Hidden `00000000-0000-4000-8000-000000017902`. Distinct evidence-only roots ensure clearStaging cannot touch media/other catalogues.

Every Incident lineage is monotonic union of old lineage and all linked records/events/accepted analysis sources. Unlink/remove/merge/split cannot declassify previously incorporated restricted content. Analysis lineage is computed from validated selected evidence, never accepted from model output. Deleted references remove OCR/annotations from library but retain minimal contributing source fingerprints in affected incident lineage. Remote analysis/export of incident-derived content checks ALL retained lineage against live originating originals; restricted, changed or unavailable contributors block it. Evidence original ID/MIME/hash/size/vaultOnly identity cannot be changed by rename/note/OCR edits. Add `VaultEgress.AI` or common requireAllowed helper so AI matches EXPORT restrictions. upsertIncident validates event source IDs, and create/edit/delete event/AI-apply use audited upsert with action detail; no hidden mutation through generic decoded JSON. ExtractedTime preserves raw text/provenance with timezone/precision uncertainty in that provenance string; epoch0 when not explicitly resolvable.

Sources read streams to authenticated EOF; consumers cannot publish before readVerified returns. Recheck original size/hash/policy and current authority before and after streaming; all scopes close on cancellation. `EvidenceAccess` root captures session authentication epoch/key identity/generation (Primary) or exact HiddenSession.Authority, exposes owner/root/leaseFactory/sources/current/close. Closing it cancels registered controller Jobs/calls and clears transient UI state. Lock/Hide/Panic and active screen retirement invoke close; external SAF handoff retains only an opaque original-auth ticket and encrypted stage/selected IDs+digest, never decrypted text. Callback requires original auth epoch still current AND resumed originating vault before fresh controller; late callback after reauth rejected. Do not keep a dismissed controller alive for import/export.

`EvidenceAi.prepare(catalog,selectedIds,imageIds,model,task,sourceReader,route):EvidenceAiPreview` returns in-memory exact payload bytes/digest and UI-safe selected IDs/text/thumbnails/estimated cost. `EvidenceAiPreview` AutoCloseable wipes bytes/bitmaps, contains captured catalog revision/source fingerprints/route identity, and a one-shot AtomicBoolean. `EvidenceAi.analyze(preview,credential,currentCatalogDigest):Analysis` must validate digest/route/current before consuming ticket and before network, then wipe credentials/body/results after parsing; calls cancellable via route.close/current. No persistent API consent token; changed model/selection/correction/route requires a new preview. Advisory responses carry only validated input evidence IDs; apply requires separate audited UI action.

`EvidenceArchive.write(plan,reader,passphrase,OutputStream):EvidenceExportReceipt` defaults encrypted; plaintext mode requires plan.plaintextConfirmed and explicit independent UI confirmation. `EvidencePdf.render(plan,reader):ByteArray` bounded20MiB; encrypted ZIP uses safe generated sourceUUID filenames, no raw path/URI. Max128 selected originals/2GiB uncompressed total, metadata4MiB, transcript2MiB, report20MiB, max256entries. Reject duplicate/absolute/traversal paths, symlinks, unsupported compression, per-entry/total expansion over quotas; all bounds enforced while streaming.

Opening GCM export: copy bounded ciphertext to a private owner-only sealed temporary file, never plaintext. First pass authenticates full GCM into a discard sink BEFORE any ZIP parsing/rendering. Then second pass reads the SAME private ciphertext file (not document provider), boundedly parses report/JSON/hash index into memory, drains/verifies every original entry/hash, and completes GCM again before exposing any report/transcript. No plaintext original is published during parse. Return an `EvidenceOpenedArchive` AutoCloseable holding only bounded report/metadata and encrypted source path for separately confirmed extraction; wipe onclose and delete ciphertext staging. Re-export plaintext requires explicit consent and another authenticated read; provider failure leaves only best-effort-deletable partial destination, never claim secure deletion. Header contains fixed KDF/version/length fields authenticated asAAD; bound beforeKDF/allocations. Owner passphrases preserved verbatim. Root SAF integration uses ciphertext staging completed before picker and original-auth ticket; no unencrypted temp.
