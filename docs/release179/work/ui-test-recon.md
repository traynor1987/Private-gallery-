## Main-thread, lifecycle and assertion pitfalls

- Do not runBlocking awaiting controller publication inside runOnIdle/Main: controller publishes Main and deadlocks. Trigger on Main, await from instrumentation thread using compose.waitUntil bounded predicates; native OCR can take up to 30 seconds per page, so give the real OCR transition a bounded ~45-second wait rather than a generic 10-second UI wait.
- Busy progress has no Compose idling integration with external IO/native OCR. waitForIdle alone does not establish completed extraction. Await exact state/semantics and inspect persisted catalogue off Main.
- EvidenceLocker closes on ON_STOP and access retirement. ComponentActivity recreation/config changes retire it; do not mutate viewport mid-test expecting the old controller to survive. New access/controller is required after reauthentication. SAF and VPN permission Activity handoff are separate Main host integration tests once wired; a ComponentActivity callback counter does not prove those flows.
- LazyColumn actions require performScrollTo/performScrollToNode before click/assertIsDisplayed. Repeated Open/Edit/Close/Title nodes need ancestors/hasAnyDescendant or dialog-scoped matchers; useUnmergedTree where necessary. Record checkbox already has contentDescription. Prefer stable unique synthetic titles/text; do not use fixed list indexes for multiple OCR versions/events.
- Native engine text is probabilistic: assert stable words (Alice, 14:35) and provenance rather than full exact OCR. Correction/search text should be a unique deterministic owner input. Keep uncertain timestamps explicitly unknown.
- Fixture teardown must release any operation latch, close controller on Main, close previews/routes, lock HiddenSession, wipe source/key arrays, and delete only fixture root. Avoid app-wide data clear/uninstall or replacing real PIN preferences.
- Core suite coverage is complementary: EvidenceAccess179Test (real owner/source/EOF policy), EvidenceController179Test (Main publication/retirement/import claims), EvidenceOcr179Test (native image/PDF/text), EvidenceAi179Test (fake route/credentials), EvidenceRouteCoordinator179Test (route lifecycle). Rendered tests should connect actual gestures to those real components without rerunning every transport permutation.
