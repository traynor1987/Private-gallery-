# Offline evidence OCR 1.7.9

`EvidenceOcr(Context).recognize(bytes, mime, rotation, current)` accepts caller-owned bytes and returns one immutable `EvidenceCatalog.Ocr`. It does not persist an extraction or modify originals. The controller must preserve the original source dimensions and timestamp claims in `Metadata`, save extraction history with `saveOcr`, and use `reviseOcr` for owner corrections. `Ocr.width/height` describe the first processed, explicitly rotated working raster; word rectangles use each page's working raster coordinates. Page numbers are zero based. A PDF's pages can have different dimensions; its word coordinates are local to each page. `pageCount` is the number of processed pages, independent of the eight extraction-version limit.

## Model preparation and packaging

The standard library is pinned to `cz.adaptech.tesseract4android:tesseract4android:4.9.0`. JitPack is restricted to that exact group. No dynamic dependency version or OpenMP variant is used.

The build's `prepareEvidence179Model` task always verifies the model before `preBuild`. `scripts/prepare_evidence179_model.sh OUTPUT_FILE` accepts an already verified output or an optional public model file in `EVIDENCE179_MODEL_CACHE`, otherwise fetches the fixed official HTTPS URL. Size and SHA256 must match before an atomic staging rename. An invalid explicit cache, truncated download, wrong digest, or failed download leaves no generated model to package. No traineddata binary is checked into source control. The generated asset source directory is `app/build/generated/evidence179Assets`, containing `tessdata/eng.traineddata`.

Only public model files are written by the runtime adapter, beneath `noBackupFilesDir/evidence179-ocr/tessdata`. Asset copy uses a unique private staging file, size/digest verification, file fsync, and rename. Existing installed models are hashed before reuse. All extraction inputs, PDF proxy buffers, bitmaps, raw text, hOCR and word results remain in memory. The adapter has no HTTP/provider fallback. Mutable working images and reusable byte/character buffers are cleared before release; immutable Java/JNI strings cannot be reliably overwritten and are left for garbage collection.

## Extraction bounds and provenance

Images are inspected before decoding, rejected above 32 MiB or pathological dimensions (100,000 pixels per side or 512 million source pixels), and sampled before allocation to a long edge at most 2048 and working pixels at most 16 million. Ordinary 48 MP inputs are supported. Rotation is explicitly 0/90/180/270; it is applied to the raster and recorded. PDFs reuse `VaultPdfPreview.page` memory-only proxy descriptors whose reads recheck captured authority. PDF pages are raster OCR; there is no separate PDF text parsing engine or active content.

The adapter processes at most 32 pages, 100,000 text characters, 100,000 words and 4,096 time hints. It uses a 30 second page budget and 120 second document budget. If a later page reaches a deadline, completed pages can be returned as partial; a first-page deadline fails locally. `partial` and the engine suffix explain `PAGE_LIMIT`, `TEXT_LIMIT`, `WORD_LIMIT`, `TIME_HINT_LIMIT`, `PAGE_TIME_LIMIT` or `DOCUMENT_TIME_LIMIT`. Cancellation/revocation returns no result, including a partial one. Original bytes are never shortened or overwritten.

Native recognition calls interruptible `getHOCRText` first. An independent monitor checks coroutine cancellation, captured authority and deadline every 25 ms and calls `stop()`. The operation waits until JNI recognition exits, then joins the monitor before opening a cached ResultIterator or freeing the bitmap/engine. Null/blank hOCR is an explicit local failure. An empty cached page returns empty text/words and unknown confidence. Text comes from cached paragraph iteration; page confidence is the arithmetic mean of available cached word confidences, with unknown pages excluded from the document mean. No TessBaseAPI UTF8/mean-confidence convenience getter is called: both can trigger a second recognition on empty/failed pages. Iterators are deleted and native instances recycled on every exit. Engines are serialized. Native `init`, bitmap decode and platform PDF render are synchronous platform/library operations; they are checked before/after and PDF proxy reads are fenced, but cannot safely be forcibly killed mid-call. Device testing must confirm practical time/cancellation behavior; no unsafe recycle race is used to impose a timeout.

Text/CSV uses a strict UTF8 decoder, validates the entire input even after the retained text limit, preserves raw text, and uses engine `UTF8_DOCUMENT`, confidence -1. Truncated text adds `PARTIAL_TEXT_LIMIT`. Native mean/word confidence remains unverified (0..100, otherwise -1); low-confidence words are retained. `EvidenceTextHints.scan` supplies raw date/time/relative hints with original uncertainty provenance and confidence -1. Participant candidates are excluded from time hints and never assigned to participants. Only an explicitly resolvable offset timestamp can have a nonzero epoch.

## Licenses and native verification

The asset directory includes the exact staged model's Apache license, a model hash/source manifest, a notice, and upstream license texts fetched from Tesseract4Android tag 4.9.0: Apache 2.0 for wrapper/Tesseract 5.5.1; Leptonica 1.85.0 license; libjpeg v9f README including redistribution terms; libpng 1.6.48 license. `license-manifest.json` records source URLs, local SHA256 and sizes.

The upstream tag's Android build uses NDK 27.2.12479018 and `-DANDROID_SUPPORT_FLEXIBLE_PAGE_SIZES=ON`; it builds all default NDK ABIs (the example list is x86, x86_64, armeabi-v7a, arm64-v8a). This is source-level support evidence only. The AAR and APK have not been resolved or built here. Root's grouped build must verify actual packaged ABI coverage, every relevant native ELF LOAD alignment >=16 KiB, APK `zipalign -c -P 16`, APK asset byte count/hash, and real API37 OCR including cancellation/revocation. Do not infer final APK compatibility from upstream build flags alone.

## Local checks

Run `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest scripts.tests.test_evidence179_model -v`. Public-model success cases use `EVIDENCE179_MODEL_CACHE` when set, or the staged public model at the documented research path; they skip clearly if absent. Fake-curl tests make no external calls. Run `EvidenceOcr179Test` as real instrumentation on API37 with the generated model packaged. Its controlled Engine/Cursor seam covers failed/empty hOCR and stop/exit/iterator/bitmap/engine ordering; real JNI cancellation/revocation uses an actual progress callback handshake with input prepared before launch, a five-second completion assertion, no-result assertions, and a subsequent successful extraction. Local Gradle could not bootstrap uncached 9.5.0 due network unavailability, so Kotlin compilation and all native/device assertions remain pending.
