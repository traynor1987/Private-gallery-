# Private Gallery 1.5 owner acceptance

These checks apply only to the final candidate whose exact source SHA, APK SHA-256, certificate, package/version and successful production upgrade evidence are recorded in `PRODUCTION_UPGRADE_READINESS.md`. A checkpoint or intermediate APK is not a substitute. No owner installation or release publication is performed by CI.

1. **Identify the installed V1.** Confirm package `uk.co.traynor.privategallery`, installed versionCode below 29, and certificate SHA-256 `94f2bfc6567f26d067d29077111cfd0ce86d38263c642ad115e43365f05b0d17`. The recovered V1 APK is code 28/name 1.0.27; the owner's current installation has not been directly inspected. Retain existing backups and recovery material. Do not send PINs, recovery keys or signing secrets in chat.
2. **Authorize this exact update.** Review the final report and APK hash, then explicitly authorize installation of that candidate. The TEST ONLY package is separate and does not update production. No installation is authorized merely by a successful automated run.
3. **Install as an update.** Android must offer to update Private Gallery. Do not uninstall, clear app data or reset the PIN to resolve an installation error. Stop and report the error if Android rejects the update.
4. **Check existing Primary data.** Unlock with the original PIN. Verify representative old photos/videos, collections, favourite collection, settings and saved WireGuard configuration. Restart the app and check again. No reimport or VPN reconfiguration should be necessary.
5. **Check separation and navigation.** Enter Hidden using its own authentication. Return to Primary through both the menu and Settings; cancel or fail Primary authentication and confirm no Primary content appears. Unlock Primary normally. Check Phone Gallery / Primary Vault selection, collections and media controls. Confirm switching/locking while previews or copies are in flight cannot display content in the wrong vault.
6. **Check real media and device controls.** Import representative real photos and 20/100/500 MiB videos into Hidden as storage permits; seek and play through different positions, then restart and verify persistence. Copy an existing Primary item to Hidden after independently authenticating both. Confirm originals remain. Exercise background timeout, explicit lock, configured screenshot on/off behaviour and authorized Primary biometrics. CI's large videos are short valid MP4s padded to test storage size; sustained high-bitrate physical playback still needs this check. The old Primary importer has a documented memory limitation for a roughly 55 MiB PNG on a 192 MiB heap; the new bounded Hidden import and existing-Primary-copy paths do not certify that old import path.
7. **Check VPN/browser and accept.** With the existing real WireGuard profile, verify browsing works when connected and fails closed when the tunnel is unavailable, including after app restart. Confirm all prior data remains available and record owner acceptance or specific failures. Publishing a release remains a separate action.

The synthetic upgrade tests prove preserved fixture PIN/media ciphertext and decrypted hashes, collections/favourite, stored settings and encrypted VPN configuration across `install -r` and restart. They do not exercise the owner's live profile, device biometrics or MainActivity PIN-entry flow, and do not establish the identity of the owner's installed APK.
