## Bounded implementation

Use the exact WG21636207a675 and its existing gVisor703fd9b7fbc0 dependency, retaining checksums and notices. A new owner-only native readiness module may use a small reviewed adapter over gVisor rather than the unsafe convenience netTun.Close/WriteNotify implementation. No WG/browser engine upgrade, second peer device, default resolver/dialer/proxy, arbitrary URLs, child-facing stream API or new browser feature.

1. Extend native packet records with immutable REAL versus PRIVATE_PROBE provenance plus fence/generation/attempt identity. REAL input is unconditional DROP during CLOSED, PROBE and prepared-before-commit, regardless of matching packet bytes. Only the native private stack can create PRIVATE_PROBE records. Recheck the immutable tag/attempt at dequeue. PROBE inbound goes solely to the private stack for registered control flows or is dropped; it never writes the Android TUN. Preserve normal OPEN protocols, options and fragmentation, protected outer sockets and existing hard-invalidation barriers.
2. Own a bounded channel.Endpoint and cancellation-aware ReadContext pump, with balanced PacketBuffer/view references. Seal flow creation and output, cancel connections/attempt, bar and join injectors, cancel/join the pump, close the endpoint once, dispose queues, close/wait the stack and join tracked operations. Do not use notification callbacks with blocking channel sends. Fix/wrap gonet early-return endpoint cleanup. No resource waits under Session, broker or native publication locks. A stuck retirement remains denied and cannot yield a readiness receipt.
3. Provide passive Android kernel port keepers: concrete Network-bound TCP/UDP sockets, reuse disabled, never connected or sent through, no streams/factory/raw socket access after construction. Hold their bindings for the whole fence/child lifetime. Pass only immutable address/family/protocol/port specifications to the private stack, which binds explicitly in its own namespace. These keepers prevent collisions with child sockets; they grant NO permission to REAL packets. Guard final disposal with trusted child/fence retirement. Prove failed private-stack connections cannot release the independent keeper binding. Bounded resource exhaustion is closed; never refill by releasing a live keeper.
4. Maintain fence-lifetime private-flow reverse-tuple tombstones across stack retirement and all WG-generation replacements until final fence retirement, including OPEN, so late decrypted replies cannot become real-TUN/child traffic. Keepers prevent collisions for unparsed/fragmented replies. Do not claim WG internal queues were flushed: already queued fixed owner control records can remain in the same protected device; native hard Invalidate still blocks their outer sends. Retire private producers and adapter resources before producing the prepared receipt, retaining the same verified WG device.
5. Preserve `VpnDnsMessage` query/ID/question/class/type, bounds, answer ownership/CNAME checks, A/AAAA behavior, numeric configured DNS and verified-TC-only TCP fallback to that server. Prefer reuse of the existing pure Java codec via bounded owner callbacks rather than divergent parsing. All exchanges use only private native datagrams/TCP, with cancellation and bounded8s DNS deadline/3s attempts. Never resolve child hostnames through this API. Retain readiness destination filtering. IPv4-only HTTPS selection is a deliberate bounded readiness choice based on the mandatory profile IPv4 route, not a claim to preserve the old resolver's family selection; ordinary IPv6 browser routing remains unchanged.
6. Fixed readiness is HTTPS GET `https://example.com/`: Host/ServerName exact, no redirects,200 and nonempty body. Use HTTP/1.1, no proxy/environment/default transport fallback, cookies, credentials or child headers; bounded headers/body sampling/connect/read/overall timing. Disable TLS client session caching. Use an explicit nonempty bounded root pool exported from the Android app default TrustManager, normal Go chain/time/hostname verification with InsecureSkipVerify=false, PLUS mandatory Android X509TrustManagerExtensions verification. Correctly map TLS1.2/1.3 authType and pass OCSP/SCT using the API37 overload, properly encoding the TLS SCT list. Any missing/throwing/rejecting validator, empty roots, malformed input, unsupported mapping or late result fails closed. This intersection may be stricter than Android; do not claim identical compatibility. No filesystem-root or reduced-validation fallback. Keep callback references until all callbacks finish, outside security/owner locks.
7. Wire bounded owner-only JNI/Java readiness methods into the Task2c bridge, keeping publication/invalidation purely atomic and callback-free. Readiness receipts bind exact fence, transport generation, replacement epoch and attempt, and are invalid after cancel/revoke. Do not open real admission merely because the probe succeeds; later authenticated child commit alone may Publish.
