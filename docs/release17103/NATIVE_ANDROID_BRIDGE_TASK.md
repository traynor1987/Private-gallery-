## Owner-private API

Expose opaque positive long fence, transport and lease handles; distinguish the process-unique transport handle from its per-fence monotonic generation value. Handles never repeat within a process and fail closed on positive signed-long exhaustion, including epoch/sequence overflow. Child IPC must never expose these handles or registration/publication APIs. Registry entries must be fully initialized before publication. Invalidate, revocation-sequence capture and Publish must use immutable/atomic registry lookup plus atomic current-transport pointers: no registry/configuration/owner mutex, Java callback, TUN I/O or blocking close inside these methods. They will run under the Hidden authentication monitor in a later task.

Operations needed: create a lifetime fence from an exclusively transferred duplicated TUN FD plus trusted MTU/name; replace its WG transport with a strictly newer generation and exact single-peer configuration; BeginProbe; exact numeric TCP/UDP tuple registration with epoch; removal; revocation sequence; atomic publication; immediate invalidation; blocking retirement; final lifetime release; bounded numeric peer handshake/rx/tx statistics. Return generic numeric failure codes, never secret IPC configuration, backend exception text, URLs or keys. Retire/replace/release may block and must be explicitly documented as forbidden inside authentication/session monitors.

Serialize or conditionally publish replacement control operations so an older delayed Replace return can never overwrite a newer transport pointer. Each transport stores its immutable replacement epoch and fence identity; BeginProbe, lease registration and Publish require the current handle and matching epoch. Validate before any destructive replacement work. Monitor-safe invalidation remains outside that control lock.

The Java protect callback is owner-provided and synchronously calls VpnService.protect on each actual outer FD through the reviewed transport Bind.Open hook. Keep its JNI global reference alive until all corresponding transport callbacks and retirement complete. Attach/detach Go threads correctly, clear/deny on Java exceptions. Never call Java while a Java authentication/session/security monitor or a bridge registry/publication lock is held. The reviewed transport's native configuration owner and bind FD-lifetime locks are intentionally held during the trusted non-reentrant protection callback; the callback must only protect the FD and must not call back into this bridge. Reference deletion must not race a blocked protect callback. Partial replacement errors must leave admission closed and the lifetime TUN retained.

Fence-level invalidation must also cover an in-progress replacement, not just the previously installed atomic transport pointer. Maintain a monotonic atomic fence revocation epoch. The trusted caller captures the expected epoch inside its authenticated replacement-admission transaction and supplies it to Replace; do not recapture it late in a worker. Invalidate advances the epoch before loading/invalidating the current transport. Replace creates the new transport CLOSED, publishes its current pointer before its final epoch comparison, and invalidates/returns denial if the expected epoch changed. BeginProbe also requires the matching replacement epoch. Include deterministic tests for invalidation before construction, during a blocked protect callback, between pointer publication and final epoch comparison, and after successful replacement. A separate generation-specific Invalidate remains available. Stale/malformed requests rejected before replacement starts must preserve an unrelated current transport; once replacement starts, errors retain reachable sealed transport/fence ownership and callback references until retirement. This is a bridge race contract, not authentication: later integration must order capture and all owner changes under HiddenSession and must never authorize a new attempt after lock.

Each native lease binds fence + transport generation + epoch + exact tuple and wraps the opaque gate.LeaseID. Remove returns success only after future admission is removed, or independently proven permanently sealed generation; unknown handles cannot release Java reservations. Reject nonnumeric, mismatched-family, malformed, oversized, zero or foreign values. No default DNS or direct fallback.

## FD ownership

Define precisely which side owns each FD before/after every success and error. Java retains its original protective PFD; the native layer receives only an owned duplicate, transferred at JNI entry and consumed on every result. Pre-adoption errors close that duplicate once; post-adoption errors close through its sole file owner. Do not copy the original upstream `CreateUnmonitoredTUNFromFD` error path: it creates an os.File and can return after Name failure without closing it, making a raw close plus finalizer unsafe under FD reuse. Use an explicitly owned unmonitored device wrapper or another demonstrably single-close adoption path. One real reader only. Retirement never closes the lifetime TUN. Final release requires an explicit external proof supplied by the future trusted owner that all sensitive children have died; this bridge cannot infer authentication or process death. Errors retain containment, never manufacture a successful retirement receipt.
