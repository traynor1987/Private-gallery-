# Task2b: pre-child probe socket reservations

Implement only a pure Java17 owner-side reservation pool and host tests. New files belong under `app/src/main/java/uk/co/traynor/privategallery/core/vpn/continuity/` and `scripts/tests/vpn/`; provide a focused host runner. No Android, JNI, Main, runtime, Gradle or workflow edits yet. This is not a C1 fix by itself.

Purpose: every future PROBE source binding must be exclusively held before any sensitive child exists, preventing delayed old child packets from matching a newly allocated parent probe tuple. A new exclusive bind after child admission does not prove temporal ownership.

Pool construction receives concrete local VPN addresses, a numeric DNS target, network-binding callbacks for Socket/DatagramSocket, and a bounded TCP slot count. Pre-create actual TCP Socket subclasses with reuse disabled, bind through the supplied callback then bind concrete address/ephemeral port. Do not use a delegating Socket facade that breaks JSSE/OkHttp. No slot refills or new socket allocations after sealing for child admission. Each TCP slot may be claimed for one connection attempt, is burned even on failure/cancellation, and never returns to availability. Exhaustion fails closed.

The generation-scoped caller supplies an owner-private registrar. Before any connect/send, register an exact family/protocol/local-address+port/remote-address+port lease; revoke it before the actual FD is released. A failed/unknown revocation must keep the descriptor parked and nonreusable, not free a still-permitted tuple. Never log tuples, URLs, DNS payloads or tokens. Pool destruction requires an external trusted release predicate proving child/fence retirement; this host class cannot establish Android policy itself.

UDP reservations stay physically bound across generations. Expose a bounded single-owner query lease rather than overriding DatagramSocket.close to silently release/reborrow during an old receive. Query cancellation removes admission first, prevents publication and waits for in-flight socket operations to leave before reuse; use bounded receive timeout. Logical query close does not release the UDP descriptor. Epoch/lease identity must prevent old closes from cancelling a newer borrower. DNS TCP fallback needs a separately claimed pre-reserved TCP socket for its concrete address family. HTTPS readiness uses concrete IPv4 bindings (mandatory profile IPv4), with future DNS adapter choosing IPv4 HTTPS results; ordinary IPv6 browser traffic is unchanged.

Interface names are implementer-owned but must be documented clearly for JNI/OwnedVpnDns integration. Provide a real SocketFactory for already-bound TCP slots, a registrar/permit abstraction with safe revoke-before-release result, UDP query send/receive/cancel/close, and an explicit final-retirement disposal path. All errors leave reservations unavailable or safely held; never silently use default sockets/resolver.

Write RED tests then implement. Host tests use loopback and an injected no-op network binder: demonstrate pre-reserved port collisions, real TCP socket/stream compatibility, exact registration before connect/send, removal before FD release, no slot reuse/refill, failure burns, exhaustion, cancellation/receive ownership, stale borrower close, parked FD on revoke failure and guarded final disposal. No test credentials or live external websites. Run Java17 compilation/checks. Report Android integration limitations; do not claim actual VPN enforcement.
