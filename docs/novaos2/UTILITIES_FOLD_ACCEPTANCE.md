# Utilities acceptance on Galaxy Z Fold

Use synthetic records in Primary Space. Record the installed version, build, Android API, display and outcome for each check. Cover and inner emulator captures illustrate the utility grid. Owner acceptance requires both physical displays.

| Utility | Owner check |
| --- | --- |
| Notes | Create a tagged checklist offline. Reopen it after launcher restart, search for its tag and verify the checked items. Verify notebook protection on a protected note. |
| Tasks | Create a recurring task with a due date, priority and reminder. Allow notifications, check the reminder at the chosen time and open the due day in Calendar. Repeat with permission denied and check the reported status. |
| Calendar | Switch between day, week and month. Schedule a shift, reopen it and explicitly hand an event to Android Calendar. Cancel the Android handoff and verify the local event. |
| Files | Choose a disposable SAF folder. Search for a document, rename or copy it using supported provider actions and open its details. Use Share file to send only the selected document to an app you choose. Check Android Downloads with and without a compatible handler. Revoke folder access and check that file actions fail safely. |
| Contacts | Deny access first, then allow and search for a synthetic entry. Dial opens the system dialler for confirmation. Hide contacts, background the app and check that it does not retain a contact list. |
| Clipboard | Explicitly paste ordinary text and save a snippet. Verify that Android-marked sensitive clipboard input is rejected and copied sensitive snippets are flagged. |
| Share Hub | Share plain text to NovaOS, cancel once, then unlock Primary and review it. Save separate copies to Notes, Tasks and a user-selected text file. Check their contents. |
| App Usage | Choose a date range and read activity with and without Usage Access. Check Sanctuary totals. Save observed daily totals, reopen after restart, and delete the saved totals. Storage is device-local and contains dates and observed durations only. Working Mode duration requires its registered integration. |
| Update Centre | Compare installed version and build with Updates & About. Open that same updater, inspect its status and available release notes, and return to Utilities. |

Repeat each layout-sensitive flow with the Samsung keyboard visible on the cover display, on the inner display, and after folding during use. Check labels, scrolling, reachable actions and safe handling of owner authentication after returning from an Android system surface. Verify that Sanctuary blocks protected handoffs. This checklist does not authorise a feature installation or production release.
