# Desktop Mode on Galaxy Z Fold

Open Desktop Mode from NovaOS systems. No network or extra permission is required for presets, pins or the calculator.

- On the cover screen, choose Gaming, select the other panel, and open a shortcut from the taskbar. Check the taskbar is reachable while the panel scrolls.
- Unfold, rotate both ways, and fold again. Check both panels appear on the inner screen and the chosen cover panel returns on the cover screen. Resize the inner divider by dragging, then use the resize buttons.
- Pin two personal apps. Reorder with a mouse drag or the accessible arrow buttons. Switch between the three presets with Alt+1, Alt+2 and Alt+3. Relaunch Nova Home and confirm the correct preset, split and pin order return.
- Choose **Open beside Nova** and select an eligible installed app. Observe where Samsung places it in portrait and landscape. Android decides whether to honor the adjacent request for that activity and windowing mode.
- Connect a compatible public presentation display. Choose **Open on** for that display, then select an eligible personal app. Repeat after disconnecting the display with the picker open. The disconnected destination must become unavailable. Record the monitor, connection and Samsung window mode.
- With Sanctuary active, confirm its foreground and app restrictions still govern each entry. Internal vault activities and other Android profiles must never appear in the placement picker.
- Cancel Android's document picker, reopen it, and verify only the chosen document's type and size are shown. Confirm it grants no directory access.

These checks require the owner's device and authorized release. Record emulator observations separately from physical acceptance.
