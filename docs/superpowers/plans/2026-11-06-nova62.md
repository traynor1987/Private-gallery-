> **For agentic workers:** Use superpowers:subagent-driven-development with one implementation writer and read-only review per checkpoint.

**Goal:** Deliver three useful secure built-in applications on the verified integrated NovaOS baseline.
**Architecture:** Extend current Kotlin/Compose and SpaceContext/EvidenceAccess capabilities. Add bounded portable archive transport and category adapters, pure independently tested game/arithmetic engines, and existing Home routing. Preserve all existing security authority.
**Tech Stack:** Kotlin/Java, Compose, Android17/API37, JCA AEAD, encrypted SpaceContext preferences, SAF, existing Gradle/CI/release gates.
**Spec:** `docs/release1711/NOVA62_SPEC.md` (owner requirements).

## Global Constraints
- Android17/API37 only; original package/certificate; no data/key reset.
- Existing `integration/novaos-1.7-home2`; isolated detached worktree, no competing writers.
- Three tested pushed checkpoints A/B/C; minimal focused CI then consolidated runtime and original-key upgrade.
- No launcher/browser/Tor rewrite; current Hidden PIN-only authority is mandatory.
- Full owner feature request is authoritative; unsupported recovery must be explicit.

## Review Focus
- Retired authority during picker/stream/publication must cancel without leaking or reporting success.
- Malicious/truncated archives must not mutate existing data or escape staging paths.
- Restore duplicate filenames and large payloads must preserve content without huge plaintext allocation.
- Game input after pause/fold or rapid queued turns must preserve legal state and private saves.
- Calculator expression edge cases and concealed sequence must neither crash nor leak/bypass PIN.
