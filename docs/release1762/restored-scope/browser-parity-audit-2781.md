2. **Fix system Back and address keyboard behavior.** Native `onBackPressedDispatcher` at Activity:227 always terminates the entire session. Primary `BrowserV2Home.kt:689-697` first clears address focus, handles fullscreen and traverses page history. Native address Go invokes `navigate` without clearing focus/hiding the IME. Implement the equivalent navigation/focus hierarchy while keeping explicit Done/lock teardown and secure website/upload cancellation.
3. **Bring native error/loading states into the shared page presentation.** Native `onReceivedError` only changes `notice`; SSL errors only cancel; there is no dedicated unavailable page with Retry/settings equivalent to Primary:820-828. `busy` changes on page start/finish/error only; there is no `onProgressChanged`, and Stop does not explicitly clear it. Test stop, stalled loading, TLS/DNS/HTTP failure, background-tab callbacks and recovery against the real child. Keep routing loss fail-closed termination. Source supports a busy indicator, not verified state equivalence.
4. **Complete native library/settings controls.** Native settings/library (`HiddenNativeBrowserDialogs.kt`, Activity:166-170,412-428) expose bookmark add/remove/open and optional per-mode history/clear, but URL-only lists lack Primary's searchable titled bookmark/history panels and dated history (`BrowserPanels.kt`). Native search is hardcoded DuckDuckGo in `navigate`, whereas Primary exposes provider selection and uses `BrowserAddressPolicy`. Add the corresponding isolated settings and accessible controls. Do not copy Primary's optional VPN requirement or disable mandatory Hidden routing, enable Tor JS, share Primary preferences, or add public device egress by inference.
5. **Make desktop mode coherent across tabs.** Native global `desktop` updates only `current.settings` (Activity:414); existing other tabs retain old UA/viewport, yet the settings label reports the global value. New tabs inherit the global flag. Primary tracks desktop mode per tab (`BrowserV2Session.kt:513-527`). Choose the shared per-tab behavior and verify switching tabs/mobile/desktop reloads without inconsistent labels or bypassing the route.
6. **Complete a reachable downloads-management flow and evidence.** Native `showLibrary` supports only Bookmarks or History; no Downloads entry/list is wired. Native settings offers Save GET media only. Parent `HiddenBrowserHome.kt:171` does offer Manage Hidden downloads by returning to Hidden Vault, which is a legitimate existing management destination; it is not an in-child list. A shared downloads action must make that destination or an isolated list reachable and understandable without losing session state unexpectedly.
