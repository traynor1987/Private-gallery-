`OwnedNativeUse` binds a secondary Native child to the exact operation, original reservation, child index and actual Native identity. It preallocates its adapter before the factory, requires the original construction entitlement before actual Native acquisition and attaches the actual Native object through the existing funded adapter. Its private late field binding never resets retirement. No raw getter or public independent close is exposed.

Int/Long SAM callbacks have primitive JVM result signatures. They run outside the private gate; overlapping or reentrant use rejects immediately. Original normal/phase retirement and authority revocation deny admission and callback results, including while the actual release worker is delayed. The funded disposer seals local use, waits for active synchronous invocation return, then calls actual Native disposal outside the gate. A self-disposer rejects before mutation. Interrupted quiescence or failed Native disposal remains failed and charged; fresh authentication remains denied. The independently funded original source/unblocker must make any blocked Native call return. A returned primitive is not publication authority.

Consumers must not retain raw Native values, publish from callbacks or await their own original. This scoped API does not establish the global raw-alias/factory-kind audit, asynchronous-retention safety, provider-copy bounds or whole producer capacity. Separate actual Native children are not folded into one composite slot.
