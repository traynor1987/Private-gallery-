# Nova Chat Lite 1.0 — owner acceptance

Install Preview0.9/code11 over the existing Preview. Do not uninstall or clear data. The main NovaOS version has not changed to2.0.

1. Confirm the ordinary WhatsApp app retains its existing authenticated session.
2. Open **Nova Chat — Friends Mode** from the drawer. Expect a neutral checking surface, then WhatsApp with the native Favourites filter selected and the small Favourites active indicator.
3. Return Home and reopen; open another app then return; rotate and fold/unfold. The retained WhatsApp page and selected Favourites should survive.
4. Reload WhatsApp. The checking cover must remain until Favourites is selected and verified again. No All Chats list should flash during initial checking.
5. If the supported control or selected-state semantics are missing, expect the compatibility cover. Retry or open the optional local Inspector. Share only its reviewed sanitised report voluntarily; never personal conversations, screenshots, codes or credentials.
6. Try Settings → Open Normal WhatsApp. Cancel should keep Friends Mode; explicit confirmation should remove the adapter and allow ordinary browsing. The dedicated Nova Chat entry enables Friends Mode again.
7. Optionally enable Sanctuary → open Nova Chat in Friends Mode. Leaving Sanctuary must not switch WhatsApp to All.
8. Confirm Home, Store, widgets, Browser V1, Recents and existing background music still work.

Configure approved favourites using WhatsApp's own controls. Previous Nova manual approval notes are preserved but do not configure this native filter. English All/Unread/Favourites or Favorites controls with supported button/tab and explicit ARIA selected state are required. Unknown interfaces remain covered; a visible Favourites badge is never treated as a conversation count.

This is a convenience filter, not a privacy/security boundary. Already-open conversations, search, notifications, filter switching and other WhatsApp navigation can expose conversations outside Favourites. No absolute concealment or encryption claim. No message text, contact identifiers, credentials or cookies are collected. The sole automated account-interface interaction is selecting the native Favourites filter; no sending, reading acknowledgement, deletion, archive or blocking action is automated.

Live WhatsApp markup and genuine Fold posture behaviour require this owner acceptance; synthetic fixtures cannot prove those. Android Home background playback remains deferred and unverified.

The generic WhatsApp web-app settings retain a legacy “Friends Mode is not implemented” warning from the older allowlist prototype. The dedicated Nova Chat entry/status describes the new native Favourites feature; stronger allowlist isolation remains unimplemented.
