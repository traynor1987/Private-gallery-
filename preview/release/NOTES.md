# NovaOS Preview 0.5 — Games, Mind & Sanctuary (EXPERIMENTAL)

Android 17 / API 37, code 5, package `uk.co.traynor.novaos.preview`. Update preview 0.4 in place; same development certificate. Production NovaOS is untouched. Do not uninstall or clear data to update.

- Existing internal Recents/Home/Back, reversible order, gesture alternatives, retained WebViews, App Mode, Edge Panel and within-NovaOS website audio preserved.
- Browser V1 has its own launcher icon, address bar, tabs, local history/bookmarks, JavaScript settings and confirmed public HTTPS downloads to Android Downloads. App Mode can open its current page in Browser V1. Existing embedded-provider restrictions remain. Authenticated/blob downloads are unsupported; no login cookies are copied to Android's download service.
- Nova Store has 90 entries: original 50 unchanged plus 40 Games listings. Games: 35 Web Apps, four portal Website Shortcuts, one Unsupported (Wordle returned Site Unavailable). Destination verification is not device/playability certification. No Verified PWA/offline claims. Per-game landscape preference/status-bar fullscreen; touch, keyboard and gamepad support depend on each website and Android may override orientation on large Fold screens.
- Nova Mind: functional 4/6 breathing, adjustable durations, pause/resume/stop, optional tone/haptic cues and reduced motion; skippable 5–4–3–2–1 grounding plus a no-count alternative; optional mood notes and journal CRUD/search with local persistence. Six original CC0 offline procedural sound textures with looping, volume and sleep timer. Sound continues within NovaOS and across rotation; pauses when the preview stops. Breathing pauses on Activity stop.
- Calm Now is available from Home, Mind, app drawer, Quick Panel and Edge. Explicit launches override a retained journal screen. Internal Recents keeps only safe app placeholders; closing an internal app clears saved screen state, and closing Mind pauses native sound. Android screenshots/Recents are protected while Mind is displayed, including exit animation.
- Sanctuary provides a calm, simplified Home with Mind, Calm Now, optional rain and relaxing favourites from Edge settings. Home returns to Sanctuary until you choose Exit Sanctuary. It does not block Android calls or notifications.
- Genuine installation/wallpaper/import/download events have timestamps, read/unread, open, delete and clear controls. Downloads are reconciled when the app resumes. No Android notification interception.

Preview journal/mood/browser storage is ordinary app-private storage, **not production-encrypted**. Notes never go to websites or external services and are not logged. Demonstration profiles are not secure Space boundaries. Live WebViews survive internal switching and rotation, not process death. Website mini-player shows only reported metadata and Return; WebView exposes no supported transport-handler interface, so website Play/Pause/Skip controls are not invented. Native calm sounds have real Play/Pause controls. Screen-off/Android background playback remains deferred.

Verification: host URL/layout/OAuth/media/navigation/Mind timing rules, catalogue/evidence/icon checks, Android app and test assembly, package/development certificate and 16KB alignment gates. Focused runtime suite requires 14 experience tests plus one dedicated configuration-upgrade test, including in-place 0.4→0.5 upgrade, browser retention, audio, navigation, Fold viewports and Mind. The actual CI outcome is appended to this release. Physical Fold acceptance remains the owner's check; emulator viewport checks do not prove physical hinge behaviour.

Owner checklist: update over 0.4; check wallpaper/layout/installed apps; play Music then Home/Recents/resume; open Browser V1 and test history/bookmarks; install 2048 and set landscape/fullscreen; open Calm Now and pause/resume; skip grounding; save/edit/reopen a synthetic journal note; play rain, rotate and return Home; enter/exit Sanctuary; test cover/inner layouts.
