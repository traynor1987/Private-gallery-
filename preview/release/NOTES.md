# NovaOS Preview0.9 — Nova Chat Lite1.0 native Favourites (EXPERIMENTAL)

Android17/API37 only, code11, package uk.co.traynor.novaos.preview. Existing development certificate. Install over the Preview without uninstalling/clearing data. Main NovaOS has not become2.0. No production merge.

Nova Chat — Friends Mode reuses the current retained WhatsApp session. It covers the page, waits for loading and supported conversation/filter structure, selects WhatsApp's native Favourites control once when needed, and requires explicit selected state before revealing. It restores after reload/navigation/reopening/resume/configuration changes without reloading or recreating the WebView. Already-active Favourites is verified without another click. Native/document-local neutral covers protect checking and unsupported transitions.

Supported contract: HTTPS web.whatsapp.com, #side containing #pane-side, a unique non-conversation filter group with fixed English All/Unread/Favourites or Favorites labels, native button/tab roles and consistent aria-selected or aria-pressed states. Badges are not interpreted as conversation counts. Conflicts, missing controls, linking interface and selection failures stay covered with explicit status, Retry, existing local Inspector, Home and confirmed Normal WhatsApp.

This automates a convenience filter, not isolation or an access-control boundary. Other chats may remain accessible through search, filter switching, notifications and other navigation. No cryptographic or absolute concealment claim. No message bodies, contact IDs/names, tokens or cookies collected. No account actions automated beyond the native filter interaction. Normal WhatsApp is available by explicit confirmation and disconnects the adapter. Previous manual-approval notes remain stored but do not configure native Favourites; use WhatsApp's own Favourites controls.

The owner confirmed native Favourites works, but live DOM semantics cannot be inspected in this environment. Synthetic fixture verification does not prove compatibility with every current WhatsApp build; unsupported markup fails closed. Inspector remains optional/local/explicit with closed sanitised reports; no remote executable updates or JS console. Actual Fold/linked-session acceptance required. Android-level background playback remains deferred. Production Primary Browser, Hidden VPN and Tor untouched.
